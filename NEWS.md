# ExpDesignR 1.0.0

## Stable release

ExpDesignR 1.0.0 establishes the first stable API for experimental design and randomization in biomedical, veterinary, agricultural, and clinical research.

### Randomization

* Simple randomization with optional allocation ratios.
* Fixed block randomization.
* Variable block randomization.
* Stratified randomization.
* Stratified block randomization.
* Cluster randomization.
* Matched-pair randomization.
* Restricted randomization with imbalance control.
* Covariate-adaptive randomization.
* Minimization randomization.

### Experimental designs

* Completely randomized designs.
* Randomized block designs.
* Full factorial designs.
* Split-plot designs.
* Latin square designs.
* Crossover designs.

### Utilities

* Allocation summaries.
* Randomization visualization.
* CSV schedule export.
* Expanded validation and reproducible seed handling.
